# Callejeandola — Go Skateboarding Day MVP

## Release target

June 21 — Go Skateboarding Day demo/MVP.

## MVP scope

The objective is to have a stable public demo that allows users to:

- Discover skate spots
- Register as skaters
- Save favorite spots
- Save events
- Open a route to a skate spot using Waze or Google Maps

## Demo flow

1. User opens Callejeandola public app.
2. User browses spots.
3. User opens a spot detail.
4. User taps Route.
5. Route Hub activates.
6. User opens Waze or Google Maps.
7. User registers as SKATER.
8. User saves favorite spots and events.

## Admin flow

1. Admin logs in.
2. Admin manages spots.
3. Admin manages events.
4. Admin manages shops and sponsors.
5. Admin manages users and roles.

## Not included in this release

- Payment gateway
- Full monetization
- Cloudinary upload
- Real map engine
- Onboarding wizard
- Email verification
- Full UI redesign

## Release priorities

1. Stability
2. Registration
3. Spots data
4. Route Hub
5. Admin corrections
6. PostgreSQL readiness
